# Список задач

Минималистичное приложение To-Do List на React и Vite. Задачи можно добавлять, отмечать выполненными и удалять. Список сохраняется в `localStorage`.

## Запуск проекта

```bash
npm install
npm run dev
```

Для продакшена:

```bash
npm run build
```
